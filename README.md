# Arquivos

Repositório para envio e compartilhamento de arquivos.

## Como enviar arquivos
1. Abra a aba **Code** deste repositório.
2. Toque em **Add file** → **Upload files**.
3. Selecione o arquivo `.jar` no seu dispositivo.
4. Aguarde o upload terminar e toque em **Commit changes**.

Depois, envie aqui o link do arquivo no GitHub.
